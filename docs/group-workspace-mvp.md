# 群聊工作空间授权与存量会话发现（首版设计）

## 范围

首版接入现有微信 iLink Adapter。工作空间持有人将指定工作空间开放给一个可信群。当前群成员可在该工作空间创建、查看和继续本群创建的会话，提交整组问题答案。工具批准与拒绝由工作空间持有人处理。个人已有会话继续通过个人会话授权进入 Channel，群入口只展示在群授权下创建的会话。

空间开放意味着群任务可在宿主允许的范围内使用该目录文件。配置界面在保存前明确展示此含义。

## 身份与授权

- 工作空间持有人由宿主可信管理记录确定。现有 `NLC_CHANNEL_WORKSPACE_GRANTS_FILE` 的 `users` 仅表示个人创建资格，不自动授予向群开放或审批资格。
- 群身份由已登记的 Adapter 帐号与群 ID 确定。调用者身份由平台认证与 Channel 身份绑定确定。两者均由服务端获取，页面请求不可自报。
- 微信入站需由 iLink 可信响应同时提供群 ID 与实际发送者 ID。当前 Adapter 只读取 `from_user_id`，并固定使用个人范围与个人回复目标，须扩展群解析及回群发送。收到一条可信群消息可以证明该次动作的实际发送者参与了这个群，不能证明其他人的成员资格。没有已验证群字段或平台拒绝回群发送时关闭群能力。
- 腾讯 iLink 协议文档把 `group_id` 列为可选消息字段，同时明确这不保证插件支持群聊。首版可用夹具验证字段处理与授权逻辑，真实群收发须等目标账号收到群消息后单独验收。参考 https://github.com/Tencent/openclaw-weixin/blob/main/docs/protocol.md#message-model 。
- 群成员资格按平台可验证的事实及其有效期登记，并在操作时复验。若平台没有完整成员名册，群内主动发送的每次操作以该次可信群消息为成员证据。主动读取和投递到群需另按工作空间持有人批准的群受众校验，不能把个人目的地改为群目的地。
- 工作空间群授权包含 `grantRef`、可信 `sessionWorkspaceRef`、群范围引用、授予者、版本、状态及有效期。管理操作由持有人发起并持久化。撤销阻止此后对群会话的读取、输入、交互应答和群投递。
- 群会话在首次执行前持久记录 `sessionRef`、`grantRef` 和实际创建者。个人会话没有群来源。会话列表同时检查群来源、当前授权、成员资格和资源代次。相同目录中原有的个人会话不会被群授权继承。
- 后端对每次群请求复验实际操作者、授权的群与工作空间、动作以及会话来源。现有 `owner == uid` 路径保留为个人访问，群访问使用明确、可撤销的委托。服务 Bearer、持有人 proof 与群消息本身均不能单独替代该委托。

## 操作规则

| 操作 | 许可主体 |
| --- | --- |
| 开放、撤销群工作空间 | 工作空间持有人 |
| 新建、读取、继续本群会话 | 当前群成员 |
| 提交问题组答案 | 当前群成员，整组一次提交 |
| 批准或拒绝工具操作 | 工作空间持有人 |

`InteractionPrompt` 的允许响应类型决定这是回答还是审批。群内每位成员的草稿按实际身份隔离。L2 复用 `interactionRef`、`expectedRevision`、响应记录和领取 CAS 协调并发。以宿主确认生效的完整答案为准，超时或结果未知时使用原请求键查询。实际响应人写入记录。审批在 L2 与宿主分别复验持有人身份，不从选项文本推导审批权。

群内新建会话复用现有固定创建请求键和工作空间映射。创建意图、群授权版本、群来源与回复目的地在首次派发前持久绑定。授权或身份改变时，原请求不得改由另一群或另一操作者接管。回复投递复用持久收件，并在发送前复验群披露依据。

## 存量个人会话

个人候选目录从 CoWork 持久化会话读取，不以 Channel `resources` 表是否有记录决定旧会话能否被发现。已验证的旧归属可同步登记并供本人勾选。只有请求自报 `user_info` 的旧记录需先完成归属核实，再进入可开放目录。群授权不会将旧个人会话转成群会话。

## 实施顺序与验收

1. 修复本人历史会话候选查询与归属登记，覆盖重启、分页、账号切换和无归属记录。
2. 接入工作空间持有人及群成员的可信身份来源，持久化空间群授权及群会话来源。
3. 将群来源接入现有会话创建、导航、消息、历史、人工交互和回复投递，并在 Python 宿主复验非持有人委托。
4. 验证两位真实群成员在同一会话并发答题，仅一份完整答案生效。验证成员退出、撤销授权、跨群引用、旧卡片、服务重启和迟到投递。

所有验收须通过真实群身份与实际后端调用。夹具回归只验证实现逻辑，不代表平台成员资格或在线模型已验收。
